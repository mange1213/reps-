Weekly report and follow-ups

Choose a week and optionally filter by representative or status. Export the selected week as an Excel workbook.

Weekly export creates an .xlsx workbook with a weekly summary and activity details. Monthly export includes a month summary, a week-by-week breakdown, and all activity details for the selected month. Choose a representative to export their report, or leave All representatives selected. CSV is available as a simple spreadsheet fallback. Keep regular backups if these records are important.

Sales representative settings

Use the representative’s name in the app header and exported reports.

Set this once on each rep’s phone. Their name will automatically fill in new activities and appear at the top of weekly and monthly exports.

Install app / GitHub setup

For the install button to work, publish the complete app package to GitHub Pages and open its HTTPS website in Chrome. Opening the HTML file directly will not offer installation.

For GitHub Pages, upload every file from the complete ZIP into the repository root: index.html, manifest.json, sw.js and the icons folder. The HTML-only download is not the complete installable package. If the in-page install prompt is unavailable, use Chrome’s ⋮ menu and choose Install app or Add to Home screen.

Data and privacy

Data is stored locally in this browser on this device. Clearing browser data, uninstalling the browser, or losing the phone may erase it. Other reps and management cannot see these entries unless you export and share them. This first version does not have logins, cloud sync, or central management access.
